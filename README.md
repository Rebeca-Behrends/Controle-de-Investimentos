# Rebeca-Luz-- Desafio Ferramenta Controle de Investimentos

## Descrição do Projeto
Este projeto é uma ferramenta prática desenvolvida em Microsoft Excel para simular investimentos em Fundos Imobiliários. O objetivo principal é auxiliar na tomada de decisão, projetando o crescimento do patrimônio e a geração de renda passiva ao longo do tempo. 

## Objetivos 
- Criação de uma ferramenta de simulação financeira funcional.
- Aplicação prática de fórmulas financeiras avançadas, como o cálculo de Valor Futuro (`VF`).
- Projeção de juros compostos, total investido e dividendos mensais.
- Documentação clara e estruturada do processo no GitHub.

## Funcionalidades da Planilha
A planilha permite que o usuário insira seus próprios dados para obter simulações personalizadas:
1. **Investimento Inicial:** Capital de partida.
2. **Aporte Mensal:** Valor investido mensalmente.
3. **Taxa de Rendimento Mensal (Dividend Yield):** Rendimento esperado do FII.
4. **Período (Meses):** Tempo de duração do investimento.

O sistema calcula automaticamente:
- O **Total Investido** (dinheiro efetivamente retirado do bolso).
- O **Patrimônio Total Acumulado** (efeito dos juros compostos).
- A **Renda Mensal** gerada ao final do período (dividendos).
